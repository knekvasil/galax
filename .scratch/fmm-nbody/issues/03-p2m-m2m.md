## What to build

Allocate multipole expansion arrays (`Vec<f64>` for Cartesian tensor coefficients) keyed by node index. Implement P2M: for each leaf, accumulate the full symmetric Cartesian tensor expansion of the Plummer-softened kernel from leaf Bodies. Implement M2M: shift a child's multipole expansion to its parent's center (binomial tensor translation). Compare reconstructed potential from multipole expansions against direct evaluation at test points.

## Acceptance criteria

- [x] Multipole arrays indexed by node ID with correct count (45 at p=8)
- [x] P2M: single Body at (dx, dy) produces correct analytic coefficients
- [x] M2M: known translation vector matches direct expansion formula
- [x] Reconstructed potential from multipole agrees with direct evaluation within truncation error at well-separated points
- [x] NaN detection after P2M and M2M (stage-boundary check)

## Completion notes

- debug_assert for NaN after each pass
- 2 unit tests: single-body P2M moments, M2M shift matches direct P2M
